# 澄心 · 情绪日记

梦幻极光风的情绪记录交互原型。打开 dist/index.html 即可查看，或将 dist 作为静态站点目录部署。

## 当前能力

- 情绪、强度、触发因素及日记记录，保存在当前浏览器 localStorage。
- 根据所选情绪调整推荐卡片。
- 响应式布局、记录弹窗、呼吸动画。
- 日回顾展示带表情的时间线、完整日记及触发因素；周回顾展示每天平均感受强度及最近的情绪表情；月回顾展示可点击的表情日历。支持前后切换、返回今天、每日多次记录和空状态。
- 记录成功后提供回顾入口及按情绪选择的调节入口。
- 一分钟呼吸支持开始、暂停、后台自动暂停及减少动效偏好。
- 三段内置原创合成轻音乐，使用 Web Audio 本机播放，无需外部音频请求；支持曲目切换、暂停/继续、音量、5/10/15 分钟定时结束，不是商业音乐曲库。
- 小计划支持模板及自定义名称、时长、今天/明天安排、编辑、持久保存、去重、完成/取消完成、移除/撤销和逾期移到今天。呼吸和音乐计划可直接开始，完成后可记录调节后的感受。
- 存储读取失败、记录结构损坏和写入失败会明确提示，保存失败保留表单，不覆盖无法读取的历史数据。
- 不支持毛玻璃时使用实体底色，支持减少透明度、提高对比度及关闭动态效果的系统偏好。

## Render 部署

1. 将本项目上传到 GitHub 仓库根目录（保留 dist 文件夹）。
2. Render 控制台选择 New → Static Site，连接该仓库。
3. Root Directory 留空；Build Command 填 echo "Static site ready"；Publish Directory 填 dist。
4. 创建静态站点，等待部署成功后使用 Render 返回的地址。

也可通过 New → Blueprint 导入仓库里的 render.yaml。

记录不跨设备同步。清除浏览器网站数据会清除本机记录；不同域名拥有独立记录。
